模型与接口设置

按顺序尝试 5 个 OpenAI 兼容接口；当前接口失败、超时或限流时会自动切换下一个。请填入你自己的 API Key（如服务商要求）。

后台接口配置文件api-config.json
你可以在服务器后台直接替换 api-config.json，或在这里导入新配置文件。导入后立即应用；导出可备份当前配置。请勿把含有真实 API Key 的配置文件公开分享。
提示：API Key 会保存在当前浏览器的 localStorage 中。不要在公共设备上保存密钥。浏览器直连第三方 API 可能遇到 CORS 限制；最稳妥的正式部署方式是通过自己的后端代理转发请求。
