# 念绪 AI 2.4.0 Pro（安全加固与 AI 生图）

## 部署

- Runtime：Node.js 18+
- Build Command：`npm install`
- Start Command：`npm start`
- 生产环境必须设置独立的 `ADMIN_ID` 与至少 12 位的唯一 `ADMIN_PASSWORD`。若仍使用示例默认值或未设置密码，生产模式会关闭管理员登录；普通用户服务仍可使用。
- 可选持久化：挂载磁盘到 `/data` 并设置 `DATA_DIR=/data`。
- `TRUST_PROXY_HOPS` 默认为 `0`，只按 TCP 对端地址限流，不信任请求自带的 `X-Forwarded-For`。只有在部署平台确实会覆盖/追加可信转发头时，才按实际可信代理层数配置；配置错误会让 IP 限流可被伪造。

## 2.4 更新内容

- 移除 AI 语音朗读、语音克隆和电话式语音聊天界面及服务端 API。
- 修复手机端管理员入口：桌面顶栏保留“管理后台”，手机从左上角菜单打开；后台内可继续进入 AI 接口设置、管理公告和查看在线用户。
- 加强请求防护：不默认信任可伪造的转发 IP；登录失败按 IP/账号组合限速；注册、聊天、搜索、生图和管理员路由分别限流；限制请求体大小与请求头数量、设置请求超时；拒绝跨站 API 写入请求；增加 CSP、HSTS（生产环境）、内容类型与权限安全响应头。
- 增强 AI 生图：提供正方形、横图、竖图、宽屏、手机竖屏比例；增加电影质感、动漫、水彩、真实摄影、3D、像素艺术、极简插画等风格快捷项；可选择让已配置的聊天 AI 将中文描述润色为更适合图像生成的提示词，也可关闭润色并直接使用原描述；结果支持下载、复用描述再生成。
- 提示词润色遵守“保留原意”的约束；图片生成仍依赖外部图片服务，实际速度、画质、可用性和内容限制取决于服务商及网络。
- 保留深色极简 UI、奶龙 AI 文字角色、联网搜索、专家模式、账号注册登录、公告、接口配置和其他原有功能。

## 功能与隐私

- 账号密码注册与登录；密码使用 scrypt 哈希保存在服务端数据目录。
- 管理员可以发布/删除公告、查看最近活跃会话和配置聊天接口。管理员身份由服务器校验，不靠前端按钮隐藏实现权限控制。
- 已移除 AI 内容检测、账号自动/手动封禁、解封及申诉功能。
- 互怼强度匹配、情绪关怀、动效、回答风格、接口失败自动切换等个性化选项保存在本设备。情绪关怀只根据文字线索调整语气，不是读心或心理诊断。
- 聊天文字发送给管理员配置的 AI 服务；联网搜索会把搜索词发送给 DuckDuckGo，并把检索摘要发送给聊天 AI。
- AI 生图提示词会发送到图片服务；若开启“AI 自动润色画面描述”，提示词还会先发送给已配置的聊天 AI。关闭该选项可以跳过润色。不要输入密码、API Key 或不希望外发的敏感信息。
- 本项目按维护者要求保留原有服务端备用 AI Key。公开部署时应优先配置自己控制的密钥、替换管理员密码，并限制后台配置文件与数据目录的访问。
- 支持 PWA 添加到手机主屏幕。管理员后台和设置弹窗在手机端支持纵向滚动；页面动效尽量轻量并遵循系统减少动态偏好。
- Render 容器内不能直接管理 UFW/iptables；如需网络层 WAF，可在服务前接入 Cloudflare 等反向代理并正确配置可信代理跳数。
