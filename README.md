# 念绪 AI 2.1 Pro（PWA + 管理后台）

## Render 部署
- Runtime: Node
- Build Command: `npm install`
- Start Command: `npm start`
- Environment: `ADMIN_ID` 设置为管理员专属 ID/口令；`NODE_ENV=production`；需要启用智谱时设置 `ZHIPU_API_KEY`
- 可选持久化：挂载磁盘到 `/data` 并设置 `DATA_DIR=/data`

## 功能
- 账号密码登录；登录页可注册新账号，账号密码使用 scrypt 哈希保存在服务器数据目录
- 管理员账号由 `ADMIN_ID` 验证，管理员密码由 `ADMIN_PASSWORD` 验证，默认密码为 `nianxu968`（正式部署建议在 Render Environment 中设置）
- 管理后台：全部账号管理、1–7 天封禁/解封、申诉队列审核、公告
- 接口设置：管理员配置 OpenAI 兼容 Chat Completions API，Key 只保存在服务器端
- 背景图片/视频、头像、字体、字号、主题偏好
- 统一设置中心：接口、版本、功能开关、服务状态与权限说明
- 低延迟优先的接口轮询：单个接口 18 秒独立超时，失败自动切换
- AI 2.0 生图：登录后通过服务器代理生成并回显图片，手机可从输入工具栏直接打开
- 联网搜索：服务端检索 DuckDuckGo 网页结果，再由已配置 AI 汇总，并在回答下展示可点击来源
- 专家模式：对复杂问题使用更严谨的假设核对、方案比较、风险说明与结果复核策略
- AI 内容检测：普通账号的聊天和生图提示会送交已配置 AI 审核；按严重程度自动封禁 1/3/7 天，管理员不参与自动封禁
- 固定 2 个服务器接口：第一个为公共入口，第二个为念绪AI 智谱 `GLM-5.3`；失败时按顺序自动切换
- 长期记忆：用户可以在设置中心添加、删除偏好记忆，按账号保存在当前设备并作为上下文参考
- 账号设置：可修改显示名字、账号 ID 和密码；修改 ID 或密码需要验证当前密码
- PWA：支持手机浏览器“添加到主屏幕”安装

## 安全/限制
- 普通用户只请求本站同源 AI 接口；服务器代发 AI 请求、内容检测与联网搜索。搜索词会发送给 DuckDuckGo，待审核文本/检索摘要会发送给已配置 AI 服务。前端不接收 API Key。管理员登录后可在接口设置中查看和修改原始 Key。
- 当前项目保留原有服务器端备用 AI Key（按维护者要求）；仅适用于私有部署，公开部署应改用个人密钥并在服务器环境变量或管理员后台管理。`.env.example` 中的默认管理员密码也必须在公开部署前替换。
- UI 使用无外部图片资源、无高耗能模糊、限制聊天 DOM 为最近 60 条并将生图尺寸限制为 768px；实际内存会受浏览器和设备影响，无法保证所有环境固定为 80MB。
- 应用层防火墙按 IP 和路由限流，包含注册/登录防爆破、AI/搜索/生图/申诉限流、请求体限制、安全响应头和可选 `BLOCKED_IPS` 黑名单。
- Render 容器内不能直接管理 UFW/iptables；如需更强的网络层 WAF，可在 Render 前接入 Cloudflare 等反向代理。
- AI 检测证据仅在管理员账号/申诉后台可查看；申诉待审期间保留，封禁到期后非待审记录最多保留 30 天。
- 若审核 AI 服务超时/返回格式不可用，会退回本地明显辱骂词兜底检测；这不等同于完整人工审核。ID-only 登录意味着用户可冒用其他普通 ID；不适合存放敏感内容。管理员权限仍由后端环境变量校验。
- Render 免费实例休眠/临时文件系统限制可能影响在线状态和数据持久化；持久数据请配置磁盘。
