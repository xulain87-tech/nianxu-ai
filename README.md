# 念绪 AI 2.8.0 Pro

## 部署

- Runtime：Node.js 18+；Build Command：`npm install`；Start Command：`npm start`。
- 默认管理员 ID 为“念绪968”，默认密码为“nianxu968”。该默认密码较弱；公开部署前请在平台私密环境变量中改设 `ADMIN_ID` / `ADMIN_PASSWORD`。
- 建议挂载持久化磁盘目录并设置 `DATA_DIR=/data`。账号、公告、接口配置和转人工会话均保存在服务端数据目录。
- `TRUST_PROXY_HOPS` 默认 `0`，仅按 TCP 对端地址限流，不信任请求自带的 `X-Forwarded-For`。只有确认代理会覆盖/追加转发头时，才按可信代理层数配置。
- AI 接口 Key 只在服务器环境变量或管理员后台保存，不发送到浏览器。智谱 GLM-Image 复用后台配置的智谱 API Key（或服务端 `ZHIPU_API_KEY`）；图片生成可能按智谱开放平台的当前价格计费。

## 功能与隐私

- 账号密码注册与登录；普通账号密码以 scrypt 哈希保存。管理员权限由服务端校验。
- 后台提供公告发布/删除、在线会话查看、AI 接口配置，以及人工客服消息查看/回复/结束会话。
- 转人工消息会包含用户账号 ID、会话内容与时间戳，保存在 `DATA_DIR/support.json`，供管理员查看；界面提醒用户不要发送密码、验证码或敏感信息。数据持久化位置应设置访问权限与备份策略。
- AI 聊天文字会发送给服务器配置的 AI 服务。若启用联网搜索，搜索词发送给 DuckDuckGo，检索摘要发送给聊天 AI。
- 生图描述会发送给智谱 GLM-Image；如果启用“AI 自动润色画面描述”，描述还会发送给已配置聊天 AI。不要输入不希望外发的敏感信息。
- 本项目保留现有服务端备用聊天 AI Key；公开部署时应使用自己控制的 Key 并替换默认管理员凭据。
- 当前已移除 AI 内容检测、封禁、解封与语音功能。手机支持 PWA 添加到主屏幕。
