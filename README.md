# 念绪 AI 2.6.0 Pro（Groq 免费接口 + 防火墙增强 + 语音回归）

## 部署

- Runtime：Node.js 18+；Build Command：`npm install`；Start Command：`npm start`。
- 默认管理员 ID 为“念绪968”，默认密码为“nianxu968”。该默认密码较弱；公开部署前请在平台私密环境变量中改设 `ADMIN_ID` / `ADMIN_PASSWORD`。
- 建议挂载持久化磁盘目录并设置 `DATA_DIR=/data`。账号、公告、接口配置和转人工会话均保存在服务端数据目录。
- `TRUST_PROXY_HOPS` 默认 `0`，仅按 TCP 对端地址限流，不信任请求自带的 `X-Forwarded-For`。只有确认代理会覆盖/追加转发头时，才按可信代理层数配置。
- AI 接口 Key 只在服务器环境变量或管理员后台保存，不发送到浏览器；源码中无任何硬编码 Key。主聊天默认优先 Groq 免费接口，留空时自动降级到 Pollinations 公共入口（无需 Key 也能回复）。智谱 GLM-Image 复用后台配置的智谱 API Key（或服务端 `ZHIPU_API_KEY`）；图片生成可能按智谱开放平台的当前价格计费。

## 2.6.0 更新内容
- 主聊天接口替换为免费方案：默认优先 Groq（`llama-3.3-70b-versatile`，免费注册、OpenAI 兼容），其次 Pollinations 公共入口（无 Key 可用，开箱即有回复），OpenRouter 免费模型与智谱 GLM 默认禁用、可在管理员后台启用；删除源码中硬编码的智谱 Key，所有 Key 仅来自环境变量或后台配置。
- 接口稳定性增强：每个上游请求 45 秒超时（AbortController）；单接口失败（网络错误/5xx/429/超时/空回复）最多重试 2 次，指数退避 500ms→1500ms；仍失败自动降级到下一启用接口；连续失败 2 次的接口进入 60 秒冷却并自动恢复探测；需要 Key 但未配置的接口直接跳过，不浪费请求。
- 防火墙增强：分层限流（登录用户按 userId 每 5 分钟 40 次，未登录走更严的 IP 限流）；登录失败渐进式锁定（5/10/20 次 → 30 秒/5 分钟/1 小时，管理员更严，错误提示含剩余锁定时间且不泄露账号是否存在）；POST/PUT 强制 JSON、按路由收紧 body 大小（chat/search 64KB，全局 1MB）；静态文件路径穿越防护（解析后必须位于 WEB_ROOT 内）；5 分钟内 4xx 超过 60 次的 IP 临时黑名单 10 分钟（与 `BLOCKED_IPS` 合并）；CSP 增加 `frame-ancestors 'none'`；`Permissions-Policy` 放开 `microphone=(self)` 供语音输入，camera/geolocation 保持禁用；仅对 URL pathname/query 过滤常见攻击特征，不过滤请求 body。
- 语音功能回归：服务端放开本站麦克风权限，前端可使用语音输入；移除奶龙聊天（后端仅保留无害的 `nailong` 参数兼容，前端不再传递）。

## 2.5.0 更新内容

- 顶栏正中新增“转人工”按钮。用户提交消息后，会进入管理员后台的“转人工消息”队列，管理员可回复或结束会话；用户打开客服窗口并点“刷新回复”查看管理员答复。
- 手机与较窄屏幕重排顶栏：奶龙按钮仍紧挨汉堡菜单，转人工按钮居中，右侧公告/管理/设置按钮保持对齐；极窄屏幕会收起标题，避免控件重叠。
- 调整 Android 手机滚动：将长聊天保持为单一页面滚动、后台区域可纵向滚动、减少固定栏模糊与消息入场动画等高负载效果，并给底部固定输入区留出安全空间。
- 聊天/提示词润色会优先尝试已启用的智谱聊天接口；在允许自动切换时，其他已配置接口可作为失败备选。
- AI 生图固定调用智谱官方 `glm-image` 模型（`POST https://open.bigmodel.cn/api/paas/v4/images/generations`），支持正方形、横图、竖图、宽屏和手机竖屏尺寸；可启用提示词润色。图片结果由智谱返回图片 URL，页面提供预览、下载/打开及复用描述。
- 删除旧的公开备用图片生成服务回退，避免用户误以为图片由智谱生成但实际来自别的图片服务。智谱不可用时显示错误，不会静默切换图片提供商。
- Service Worker 缓存版本已更新，防止手机继续加载旧顶栏与旧生图逻辑。

## 功能与隐私

- 账号密码注册与登录；普通账号密码以 scrypt 哈希保存。管理员权限由服务端校验。
- 后台提供公告发布/删除、在线会话查看、AI 接口配置，以及人工客服消息查看/回复/结束会话。
- 转人工消息会包含用户账号 ID、会话内容与时间戳，保存在 `DATA_DIR/support.json`，供管理员查看；界面提醒用户不要发送密码、验证码或敏感信息。数据持久化位置应设置访问权限与备份策略。
- AI 聊天文字会发送给服务器配置的 AI 服务。若启用联网搜索，搜索词发送给 DuckDuckGo，检索摘要发送给聊天 AI。
- 生图描述会发送给智谱 GLM-Image；如果启用“AI 自动润色画面描述”，描述还会发送给已配置聊天 AI。不要输入不希望外发的敏感信息。
- 本项目不在源码中硬编码任何 AI Key；公开部署时应使用自己控制的 Key 并替换默认管理员凭据。
- 当前已移除 AI 内容检测、封禁与解封；语音输入功能已回归（浏览器麦克风权限仅限本站）。手机支持 PWA 添加到主屏幕。
