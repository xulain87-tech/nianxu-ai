# 念绪 AI 2.2.2 Pro Voice Studio（PWA + 管理后台）

## Render 部署
- Runtime: Node
- Build Command: `npm install`
- Start Command: `npm start`
- Environment: 设置专属 `ADMIN_ID` / `ADMIN_PASSWORD`，使用 `NODE_ENV=production`；需要启用智谱时可设置 `ZHIPU_API_KEY`
- 可选持久化：挂载磁盘到 `/data` 并设置 `DATA_DIR=/data`

## 功能
- 账号密码注册与登录；密码使用 scrypt 哈希存入服务端数据目录
- 管理员账号由环境变量验证；管理员后台可发布/删除公告、查看最近 90 秒内活跃的会话
- 已移除 AI 内容审核、账号自动/手动封禁、解封和申诉流程；原有风控记录不再参与登录或聊天判断
- 互怼强度感知：聊天模型在正常生成回答时判断用户是否明确辱骂 AI，并按 0–3 档匹配机智回嘴；只用于语气，不另发审核请求、不限制账号，也不高于用户强度
- 回复边界：不使用仇恨/歧视词、身份攻击、性/家庭羞辱或威胁；用户认真求助、低落或处于危机时停止回骂并优先支持
- 个性化设置：互怼强度匹配、情绪关怀、动态效果、回答风格（简洁/平衡/详细/活泼）、接口失败自动切换、语音音色
- 情绪关怀根据文字线索谨慎调整语气；不是读心或心理诊断
- 管理员可配置 OpenAI 兼容 Chat Completions API；聊天 Key 仅由服务端保存
- 背景图片/视频、头像、字体、字号、深浅主题；可添加与管理本机长期记忆
- AI 生图：站内创意画布提供描述框和风格快捷词，服务器代理请求并返回结果；手机可从输入工具栏使用
- AI 语音朗读：每条 AI 回复均可点按朗读；提供 10 种女声风格（含萝莉/甜妹/御姐）、10 种男声风格（含叔音）及奶龙软萌俏皮风格预设，并支持试听、旋律朗读实验模式和电话式语音聊天
- 联网搜索：服务端从 DuckDuckGo 获取结果，再由已配置 AI 汇总并展示可点击来源
- 专家模式：核对假设、比较方案、解释不确定性并复核结论
- PWA：支持手机浏览器“添加到主屏幕”安装

## 隐私、安全与限制
- 聊天文字会发送到管理员配置的 AI 服务，用于回答及按设置调整语气；联网搜索词会发送给 DuckDuckGo。互怼强度在生成回答时由同一模型估计，不会调用独立内容审核服务。
- 用户设置、头像和长期记忆保存在当前设备；聊天记录不由本网页后端保存。不要把密码、API Key 或其他敏感内容写入聊天/记忆。
- 语音使用浏览器/设备本地 Speech Synthesis，不把待朗读文字发送到语音服务。20 个男女声音选项是 pitch/rate 风格预设，另有奶龙风格预设；实际底层音色依设备提供的中文语音而异，并非官方原声或声音克隆，也不是独立云端声线；没有中文语音包时需在 Android 系统安装/启用中文 TTS。语音通话依赖浏览器 SpeechRecognition/SpeechSynthesis API 和麦克风权限，不是拨打真实手机号/PSTN 电话。旋律朗读是分句变调的实验效果，不是 AI 歌声合成。
- 应用仍有 IP/路由限流、注册/登录防爆破、请求体限制、安全响应头及可选 `BLOCKED_IPS`，这些是防滥用保护，不是辱骂内容检测。
- 当前项目按维护者要求保留原有服务端备用 AI Key；仅适用于私有部署。公开部署应使用自己的密钥，并在公开前替换默认管理员密码。
- UI 避免持续背景模糊，动效限定为轻量淡入/微浮动，聊天 DOM 最多保留 60 条；实际性能仍受浏览器和设备影响。
- Render 容器内不能直接管理 UFW/iptables；需要网络层 WAF 时可在 Render 前接入 Cloudflare 等反向代理。
- ID-only 登录意味着用户可能冒用其他普通 ID，不适合存放敏感内容。管理员权限仍由后端环境变量校验。
- Render 免费实例休眠/临时文件系统限制可能影响在线状态和数据持久化；需长期保存的数据请配置持久磁盘。
