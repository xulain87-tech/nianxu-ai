# 念绪 AI 2.3.0 Pro（PWA + 管理后台）

## Render 部署

- Runtime：Node
- Build Command：`npm install`
- Start Command：`npm start`
- 环境变量：设置专属 `ADMIN_ID` / `ADMIN_PASSWORD`，生产环境使用 `NODE_ENV=production`。语音功能从服务端读取 `ZHIPU_API_KEY` 或已配置的智谱接口密钥；密钥不会传给浏览器。
- 可选持久化：挂载磁盘到 `/data` 并设置 `DATA_DIR=/data`。

## 功能

- 账号密码注册与登录；密码使用 scrypt 哈希保存在服务端数据目录。
- 管理员可发布/删除公告、查看最近活跃会话以及管理聊天接口。
- 已移除 AI 内容检测、账号自动/手动封禁、解封及申诉流程；保留登录限流和常规请求防护。
- 互怼强度匹配：聊天模型根据用户是否明确辱骂 AI，按 0–3 档给出不升级的机智回嘴；不另发审核请求，也不限制账号。避免仇恨歧视、身份攻击、家庭羞辱和威胁；遇到认真求助、低落或危机表达时优先支持。
- 个性化设置：互怼强度、情绪关怀、动效、回答风格、接口失败自动切换等。
- 情绪关怀仅根据文字线索调整语气，不是读心或心理诊断。
- 管理员可配置 OpenAI 兼容 Chat Completions API；聊天密钥保存在服务端。
- 背景图片/视频、头像、字体、字号、主题、长期记忆、联网搜索、专家模式和 AI 生图。
- 奶龙 AI 文字角色：左上角进入原创软萌小龙聊天模式，提供笑话、猜谜、故事、安慰、鼓励和问答玩法；不代表官方角色或原声。
- **智谱本人音色克隆：** 可录制或上传本人/已获授权的 MP3/WAV 样本，经明确勾选同意后由服务端转交智谱 GLM-TTS-Clone；每个账号浏览器最多保存 10 个音色 ID/显示名，可调语速、音量并试听。每条 AI 消息可手动朗读。
- **智谱语音聊天：** 左上角进入网页内逐轮语音聊天；按“开始录音”说话，再按一次发送。音频经智谱 GLM-ASR-2512 转为文本，使用现有聊天 AI 回复，再由 GLM-TTS 以已选本人克隆音色播报。每段录音最多 30 秒。
- 移动端 UI 参考用户提供的视频，采用黑/炭灰极简风、彩色功能图标、大圆角、侧滑导航及底部“工作 / AI 创作 / 帮我写作 / 话题答疑”快捷栏。
- PWA 支持手机浏览器“添加到主屏幕”安装。

## 隐私、限制与安全

- 聊天文字会发送到管理员配置的 AI 服务；搜索词会发送给 DuckDuckGo，搜索摘要会发送给聊天 AI。
- 创建音色前需要勾选声音权利与智谱处理同意。样本仅在用户点击创建后由网站服务器以内存方式转发，不写入网站项目数据文件；智谱侧处理和保留受其服务条款/隐私政策约束。网页只在当前设备 localStorage 保存返回的音色 ID、显示名和本地播放参数。删除本机记录不等于删除智谱侧音色，请按智谱平台提供的管理方式处理。
- 语音聊天需要 HTTPS、浏览器麦克风权限及支持 MediaRecorder/AudioContext 的浏览器。每轮录音最多 30 秒，并发送智谱 ASR 识别；这是网页内的逐轮语音聊天，不是拨打真实电话号码，也不是低延迟全双工电话。模型合成延迟与 API 网络状况有关。
- 智谱官方音色克隆指南说明约 3 秒样本可用于克隆；建议选择安静、清晰的 3–30 秒录音。克隆与语音合成会消耗智谱 API 额度/费用，具体按智谱账户价格为准。
- 语音相关官方接口： [音色复刻](https://docs.bigmodel.cn/api-reference/%E6%A8%A1%E5%9E%8B-api/%E9%9F%B3%E8%89%B2%E5%A4%8D%E5%88%BB)、[文件上传](https://docs.bigmodel.cn/api-reference/%E6%96%87%E4%BB%B6-api/%E4%B8%8A%E4%BC%A0%E6%96%87%E4%BB%B6)、[文本转语音](https://docs.bigmodel.cn/api-reference/%E6%A8%A1%E5%9E%8B-api/%E6%96%87%E6%9C%AC%E8%BD%AC%E8%AF%AD%E9%9F%B3)、[语音转文本](https://docs.bigmodel.cn/api-reference/%E6%A8%A1%E5%9E%8B-api/%E8%AF%AD%E9%9F%B3%E8%BD%AC%E6%96%87)。
- 应用仍有 IP/路由限流、注册/登录防爆破、请求体限制、安全响应头及可选 `BLOCKED_IPS`；这些不是辱骂内容检测。
- 当前项目按维护者要求保留原有服务端备用 AI Key；该配置仅适合私有部署。公开部署应使用自己的密钥并替换默认管理员密码。
- 动效尽量轻量，并遵循系统减少动态偏好；移动端滚动以减少嵌套滚动卡顿。实际性能仍取决于浏览器和设备。
- Render 容器内不能直接管理 UFW/iptables；需要网络层 WAF 时可在 Render 前接入 Cloudflare 等反向代理。
- ID-only 登录不适合存放敏感内容；管理员权限由后端校验。Render 免费实例休眠/临时文件系统限制可能影响在线状态和数据持久化，需长期保存的数据请配置持久磁盘。
