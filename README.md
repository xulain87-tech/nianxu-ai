# ASTRION 1.1.9

ASTRION 是一个 Node.js 单体聊天 Web 应用，包含账号登录、AI 聊天、联网搜索、智谱生图、公告、外观设置与管理控制台。

## 部署

- 要求 Node.js 18 或更新版本；安装依赖：`npm install`；启动：`npm start`。
- 部署时必须在**服务端私密环境变量**中配置 `ADMIN_ID`、`ADMIN_PASSWORD` 和 `GROQ_API_KEY`。示例变量见 `.env.example`；不要把实际值写入源码、公开仓库或 ZIP 包。由于 Key 已通过对话发送，建议在 Groq 控制台轮换后再部署。
- `ADMIN_ID`/`ADMIN_PASSWORD` 用于授权登录；登录页面没有管理员专用入口，也不会回显真实账号 ID。授权会话通过 HttpOnly Cookie 保存。
- 建议将 `DATA_DIR` 指向具备访问限制的持久化磁盘。账号、公告、自定义 AI 与共享接口配置保存在此目录。
- `TRUST_PROXY_HOPS` 默认为 `0`。只有确认反向代理可信并会正确覆盖转发头时，才设置可信代理层数。

## AI 接口

- 聊天接口固定为 5 个服务端槽位。第 1 槽固定为 Groq `openai/gpt-oss-120b`，聊天地址为 `https://api.groq.com/openai/v1/chat/completions`，密钥只通过 `GROQ_API_KEY` 服务端环境变量提供。
- 管理员可在「控制台 → AI 接口设置」中配置其余 4 个兼容接口；配置为**全站共享**，所有登录用户共用。未配置的备选槽位默认关闭。
- 第 1 槽只从 `GROQ_API_KEY` 服务端环境变量读取 Key，不提供浏览器输入框。其余 4 槽由授权管理员在登录后的控制台录入；Key 通过同源授权请求提交到服务端，读取配置只返回是否已配置，不回传 Key，输入也不会写入浏览器 Local Storage。服务器配置文件权限设为 `0600`；生产环境的备用接口地址必须为公网 HTTPS，不能指向本机或内网。
- AI 聊天服务端会过滤客户端提交的 `system` 角色消息，并由服务端生成系统提示，避免浏览器端伪造系统级指令。用户创建的角色设定与记忆作为不可信参考文本处理。
- AI 生图仍调用智谱 GLM-Image，需另行配置可选的 `ZHIPU_API_KEY`；图片和聊天请求会发送到已配置的 AI 服务。启用联网搜索时，搜索词会发往 DuckDuckGo，检索摘要会交给 AI 总结。请勿提交不希望发送至外部服务的敏感信息。

## 公告与界面

- 管理员可在控制台发布、删除全站公告。登录成功或恢复会话后，公告中心自动弹出；没有公告时显示清晰的空状态，管理员可直接开始撰写。
- 外观设置支持字体大小和背景；账号切换、退出会话均调用服务端注销接口。
- 移动端聊天输入区采用独立工具栏行，附件、搜索、专家和生图按钮不会与输入框重叠，并为底部安全区预留空间。

## 验证

```bash
npm test
node --check server.js
```

`npm test` 使用本机临时 HTTP 模拟上游与临时数据目录，覆盖健康检查、授权/普通账号登录、五槽共享配置、主槽密钥隔离、HTTPS 地址校验、密钥脱敏、系统消息隔离、AI 竞速与回退、公告以及注销；不会调用真实 AI 服务或使用生产数据。
